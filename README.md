# 守れるいのち

**暮らしの防災アプリ**<br>
知る。備える。迷わず動く。

「守れるいのち」は、生活環境のリスク診断、家族構成に合わせた備蓄管理、地域の公的防災情報、緊急連絡先、災害時の行動ガイドを一つにまとめた防災PWAです。

- 完全無料
- 広告なし
- アカウント登録不要
- スマートフォン、タブレット、PCにインストール可能
- 主要機能はオフラインで利用可能
- 診断回答や備蓄情報は利用者が選んだ方法で端末内に保存
- 外部通信は公的情報を取得するときだけ、内容を示して個別に確認
- ソースコード、診断方法、根拠資料を公開

公開ページ: <https://epsilon-lab-atelier.github.io/mamoreru-inochi/>

## このアプリでできること

### 生活環境のリスク診断

地域・地形、住まい、家族の支援ニーズ、ライフライン、避難・連絡を質問形式で確認します。

結果は「災害に遭う確率」ではありません。地震、洪水、津波、土砂災害、暴風、火災、停電・断水、避難・孤立などについて、**備えを優先したい度合い**を別々に表示します。

不明な質問には「わからない」「あとで確認」を選べます。不明項目を危険とも安全とも決めつけず、判定の確かさと確認リストへ反映します。

### 備蓄チェックとローリングストック

家族構成から、最低3日ラインと安心7日ラインを計算します。水、食料、携帯トイレ、常用薬、乳幼児用品、ペット用品など、代えにくい重要項目は個別に判定します。

備蓄品には品名、数量、単位、賞味期限・使用期限、保管場所、開封状況を登録できます。期限切れや期限が近い品を見つけ、普段使いしながら補充するローリングストックを支援します。

### 家の安全と家族の防災計画

寝室、家具、玄関、窓、火災、停電、断水、大雨・台風への対策を確認できます。集合場所、避難先、連絡方法、迎え、支援が必要な人、ペットへの対応も記録できます。

### 地域情報

自宅、職場、学校、実家など複数の地点を登録し、必要なときだけ次の公的情報を取得できます。

- J-SHIS: 選択地点の今後30年間の地震動確率
- 国土地理院: 災害種別ごとの指定緊急避難場所、指定避難所、指定福祉避難所
- 気象庁: 選択地域の警報・注意報
- 地理院地図: 選択地点周辺の小さな地図と公式地図への導線

外部通信の前には、送信先、送る情報、利用目的を表示します。EpsilonLabへ位置情報や取得結果を送る処理はありません。取得済み情報には時刻を表示し、最後に取得した内容は端末内で確認できます。

### 緊急連絡先

119、110、118、#7119、#8000、#9110、171、#9910、中毒110番などを、用途と注意点とともに一覧表示します。

番号を押しても直ちに発信せず、用途を確認する画面を一度表示します。家族、自治体、水道、電力、管理会社、学校、かかりつけ医などの連絡先も端末内へ登録できます。

### 災害時モード

初回設定や保存データのロックを経由せず、地震、津波、大雨・洪水、土砂災害、台風・暴風、火災、停電、断水、閉じ込め・孤立の行動ガイドを開けます。

各画面は「今すぐすること」「避けること」「安全を確保した後」の順に表示し、状況に関係する緊急連絡先も案内します。

### 印刷とバックアップ

診断結果、備蓄、家の安全、家族計画をA4印刷またはPDF保存できます。端末変更やブラウザのデータ消去に備えて、JSON形式のバックアップも書き出せます。

## 使い始める

1. 最初の画面で、入力内容の扱いを確認します。
2. 保存しない、結果だけ保存、端末保存、暗号化保存から選びます。
3. リスク診断を行うか、後で行うかを選びます。
4. 備蓄、家の安全、家族計画、地域情報を必要に応じて更新します。
5. 「インストールと更新」画面を確認し、ホーム画面へ追加します。

災害が起きている場合は、初回設定を行わず「今、災害が起きている」から行動ガイドを開けます。

## インストールと更新

PWA対応環境では、App StoreやGoogle Playを経由せず、ホーム画面へ追加できます。アプリ内の「インストールと更新」に、iPhone・iPad、Android、PCそれぞれの手順があります。

新しい版を検出した場合は、画面上部に更新案内を表示します。入力中に自動で再読込せず、利用者が「更新する」を選んだ時点で切り替えます。

更新方法とオフライン動作の詳細は `docs/OFFLINE_AND_UPDATES.md` にあります。

## 保存とプライバシー

| 保存方法 | 内容 |
|---|---|
| 保存しない | 画面を開いている間だけ利用し、再読込や終了で消去 |
| 診断結果だけ保存 | 質問への回答を残さず、結果の要約と表示設定だけ保存 |
| この端末に保存 | 診断、備蓄、地域情報、連絡先などをブラウザ内へ保存 |
| 暗号化して保存 | 保存内容をAES-GCMで暗号化し、パスフレーズで開く |

通常の診断回答、家族構成、備蓄、賞味期限、家族計画は、EpsilonLabやGitHubのサーバへ送信しません。

地域情報を取得するときだけ、利用者の許可に基づき、選択地点の緯度・経度または地域コードを該当する公的機関へ送ります。通信履歴は端末内で確認・削除できます。

同じ端末・同じブラウザを使う人は、暗号化していない保存内容を開ける場合があります。ブラウザのデータ消去、端末故障、パスフレーズ忘れで情報を失う可能性もあります。

詳しくは `docs/PRIVACY.md` を参照してください。

## オフライン利用の範囲

初回にオンラインで読み込み、Service Workerの準備が完了すると、診断、備蓄、緊急連絡先、災害時ガイドなどの主要機能をオフラインで使えます。

現在の警報、公的データの更新、新しい地図タイルの取得には通信が必要です。オフラインでは、最後に端末へ保存した情報を取得時刻付きで表示します。古い情報を現在の情報とみなさず、通信が使える場合は公式情報を確認してください。

## 安全上の注意

このアプリは行政機関の公式アプリではありません。診断は、災害の発生、個人の被害、建物倒壊、生命の危険を予測するものではなく、安全を保証しません。

緊急時は現在地の状況と、公的機関、消防、警察、海上保安庁、医療機関、自治体の指示を優先してください。

- 火災・救急・消防による救助: 119
- 事件・交通事故: 110
- 海上の事件・事故: 118

川、湖、池、用水路、プールなどで消防による救助が必要な場合は119です。

## 対応環境

最新のSafari、Chrome、Edge、Firefoxを主な対象としています。ブラウザやOSによって、インストール、位置情報、永続保存、共有などの表示や動作が異なる場合があります。

JavaScript、IndexedDB、Service Worker、Web Crypto APIに対応していない環境では、一部機能を利用できません。
