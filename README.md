# 守れるいのち

**暮らしの防災アプリ**  
知る。備える。迷わず動く。

「守れるいのち」は、生活環境のリスク診断、家族構成に合わせた備蓄チェック、賞味期限管理、家の安全確認、家族の防災計画、災害時の行動ガイドを一つにまとめた防災PWAです。

- 完全無料
- 広告なし
- アカウント登録不要
- スマートフォン・タブレット・PCにインストール可能
- 主要機能はオフラインで利用可能
- 診断回答や備蓄情報は外部へ送信しない設計
- ソースコードと診断方法を公開

公開ページ: <https://epsilon-lab-atelier.github.io/mamoreru-inochi/>

## このアプリでできること

### 生活環境のリスク診断

地域・地形、住まい、家族の支援ニーズ、ライフライン、避難・連絡を質問形式で確認します。

結果は「災害に遭う確率」ではありません。地震、洪水、津波、土砂災害、暴風、火災、停電・断水、避難・孤立について、**備えを優先したい度合い**を別々に表示します。

不明な質問には「わからない」「あとで確認」を選べます。不明項目を危険とも安全とも決めつけず、判定の確かさと確認リストへ反映します。

### 備蓄チェック

家族構成から、次の二つの目安を表示します。

- 最低3日ライン
- 安心7日ライン

水、食料、携帯トイレ、常用薬、乳幼児用品、ペット用品、照明、電源、ラジオ、ヘルメットなどを項目別に確認します。重要項目が不足している場合、他の用品が多くても総合点だけで達成扱いにはしません。

アドバンスモードでは、断水、停電、物流停止などを想定する日数を変更できます。

### 備蓄リストとローリングストック

品名、数量、単位、賞味期限・使用期限、保管場所、開封状況を登録できます。期限切れ、30日以内、60日以内などを表示し、普段の生活で使って補充するローリングストックを支援します。

### 家の安全チェック

寝室、居間・キッチン、玄関・避難経路、大雨・台風、電気・水・ガスを確認します。家具固定だけでなく、配置変更や枕元の履物など、すぐに始められる対策も含みます。

### 家族の防災計画

集合場所、災害別の避難先、電話がつながらない場合の連絡方法、学校や施設への迎え、支援が必要な人、ペット、電気・ガス・水の確認ルールを記録できます。

### 災害時モード

初期設定や保存データのロックを経由せず、次の行動ガイドを開けます。

- 地震
- 津波
- 大雨・洪水
- 土砂災害
- 台風・暴風
- 火災
- 停電
- 断水
- 閉じ込め・孤立

各画面は「今すぐすること」「避けること」「安全を確保した後」の順に表示します。

### 印刷・PDF保存

診断結果、備蓄、期限、家の安全、家族計画を一つのページにまとめ、A4印刷またはPDF保存できます。印刷物には個人情報が含まれる場合があるため、保管場所と共有範囲に注意してください。

## 使い始める

1. 最初の画面で、入力内容の扱いを確認します。
2. 保存方法を選びます。
3. 生活環境のリスク診断を行うか、後で行うかを選びます。
4. 必要に応じて備蓄、家の安全、家族計画を更新します。
5. スマートフォンではホーム画面へ追加しておくと、災害時に開きやすくなります。

アプリ内の「ヘルプ」に、iPhone、iPad、Android、PCでの追加方法と、オフライン準備の確認方法があります。

## 保存とプライバシー

次の4つから選べます。

| 保存方法 | 内容 |
|---|---|
| 保存しない | 画面を開いている間だけ利用し、再読み込みや終了で消去 |
| 診断結果だけ保存 | 回答そのものを残さず、診断結果と表示設定だけ保存 |
| この端末に保存 | 診断、備蓄、家の安全、家族計画をブラウザー内へ保存 |
| 暗号化して保存 | 保存内容をAES-GCMで暗号化し、パスフレーズで開く |

診断回答、家族構成、備蓄、賞味期限、家族計画を、EpsilonLabやGitHubなどの外部サーバーへ送信する処理はありません。広告、アクセス解析、外部JavaScript、外部フォントも使用していません。

同じ端末・同じブラウザーを使う人は、暗号化していない内容を開ける場合があります。ブラウザーのデータ消去、端末故障、パスフレーズ忘れで失われる可能性もあります。必要な場合はバックアップを書き出してください。

## オフライン利用

初回にオンラインで正常に読み込み、Service Workerの準備が完了すると、主要な画面をオフラインで利用できます。

現在の警報、避難指示、近隣避難所は自動取得しません。災害時には、自治体、気象庁、消防、警察、ライフライン事業者などの最新情報を確認してください。

## 安全上の注意

このアプリは行政機関の公式アプリではありません。診断は、災害の発生、個人の被害、建物倒壊、生命の危険を予測するものではなく、安全を保証しません。

緊急時は、現在地の状況、公的機関、消防、警察、医療機関の指示を優先してください。火災・救急・救助は119、事件・事故は110です。

薬、医療機器、アレルギー、乳幼児用品などは、医師、薬剤師、機器事業者、製品の案内を優先してください。

## 根拠と透明性

アプリ内の「根拠と出典」で、備蓄計算、公的資料、内容確認日、診断方法を確認できます。

診断は、質問への回答を決定論的な規則で計算します。同じ回答には同じ結果を返し、生成AIや外部AIサービスへ回答を送りません。

詳しい設計は次の文書にあります。

- `docs/DIAGNOSIS_RULES.md`
- `docs/PRIVACY.md`
- `docs/DATA_SOURCES.md`
- `docs/ACCESSIBILITY.md`
- `docs/ARCHITECTURE.md`

## 対応環境

最新のSafari、Chrome、Edge、Firefoxを主な対象としています。ブラウザーやOSによって、インストール、永続保存、ファイル共有などの表示や動作が異なる場合があります。

JavaScript、IndexedDB、Service Worker、Web Crypto APIに対応していない環境では、一部の保存・オフライン・暗号化機能を利用できません。

## 不具合・改善提案

公開リポジトリのIssueで受け付けます。

報告には、住所、氏名、病歴、家族構成、正確な位置情報、実際のバックアップファイルなどを書かないでください。必要な場合は、個人情報を除いた再現手順だけを共有してください。
