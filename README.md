# 守れるいのち

**暮らしの防災アプリ**
知る。備える。迷わず動く。

「守れるいのち」は、生活環境のリスク診断、家族構成に合わせた備蓄管理、地域の公的防災情報、家族の防災計画、緊急時の行動を一つにまとめた無料の防災PWAです。

公開ページ: <https://epsilon-lab-atelier.github.io/mamoreru-inochi/>

- 完全無料
- 広告なし
- アカウント登録不要
- スマートフォン、タブレット、PCへインストール可能
- 主要機能はオフラインで利用可能
- 診断回答や備蓄情報は、利用者が選んだ方法で端末内に保存
- 公的情報の取得は、送信先、内容、目的を示して個別に確認
- ソースコード、診断方法、根拠資料を公開

## スマホに入れて使う

このアプリは、Webで試すだけでなく、スマホのホーム画面へ入れて持ち歩けます。アプリストアは使いません。

ホーム画面へ追加すると、次の利点があります。

- 災害時にURLを探さず、アイコンからすぐ開ける
- 災害時の行動ガイドをオフラインでも確認できる
- 診断結果、備蓄、家族の防災計画を持ち歩ける
- 新しい版を同じアイコンから利用できる

アプリ内の「スマホに入れる」に、iPhone、iPad、Android、PCごとの手順があります。noteやSNS内の画面で追加できない場合は、SafariやChromeなどの標準ブラウザで開いてください。

## 主な機能

### 生活環境のリスク診断

地域・地形、住まい、家族の支援ニーズ、ライフライン、避難・連絡を質問形式で確認します。

結果は「災害に遭う確率」ではありません。地震、洪水、津波、土砂災害、暴風、火災、停電・断水、避難・孤立などについて、**備えを優先したい度合い**を別々に表示します。

不明な質問には「わからない」「あとで確認」を選べます。不明項目を危険とも安全とも決めつけず、判定の確かさと確認リストへ反映します。

### 備蓄チェックとローリングストック

家族構成から、最低3日ラインと安心7日ラインを計算します。水、食料、携帯トイレ、常用薬、乳幼児用品、ペット用品など、代えにくい重要項目は個別に判定します。

アドバンス備蓄では、高層住宅、乳幼児、医療機器、浸水前避難、夏や冬の停電、道路寸断などの状況を選び、想定日数を調整できます。飲料水のおよその重量も表示します。

備蓄品は、自宅、非常持出袋、職場・学校、車、実家・別宅などへ分けて登録できます。品名、数量、賞味期限・使用期限、詳しい保管場所、開封状況を管理し、期限が近い品のローリングストックを支援します。

### 家の安全

寝室、家具、玄関、窓、火災、停電、断水、大雨・台風への対策を確認できます。費用のかからない配置変更から始め、寝室と避難経路を優先します。

### 家族の防災計画とQR共有

次の内容を記録できます。

- 第一・第二の集合場所
- 地震、洪水、津波、土砂災害、火災ごとの避難先
- 電話がつながらない場合の連絡方法
- 子どもの迎え
- 支援が必要な人
- ペット
- 電気、ガス、水道が止まった場合の対応
- 通らない道や場所
- 次回の見直し日

共有する項目を選び、QRコード、共有リンク、JSONファイルで家族へ渡せます。電話番号、正確な位置、支援情報などは標準では共有しません。受け取った側は内容を確認してから端末へ取り込みます。

### 防災訓練

3分、5分、10分から選び、実物と行動を確認します。

- 夜中の大地震
- 大雨での避難
- 停電と断水
- 家族が別々の場所にいる場合
- 自宅火災
- 道路寸断・孤立
- エレベータ停止
- スマホの通信がつながらない場合

点数は付けません。「今回確認できたこと」と「次回までに行うこと」を残し、備蓄や家族の防災計画へ反映できます。次回の訓練日はカレンダーファイルとして書き出せます。

### 地域情報と防災地図

自宅、職場、学校、実家など複数の地点を登録できます。地点は次の方法で選べます。

- 現在地から探す
- 住所や施設名から探す
- 地図から選ぶ
- 詳細設定で座標を直接入力する

利用者が許可した操作のときだけ、公的な情報提供元へ問い合わせます。

- J-SHIS: 選択地点の今後30年間の地震動確率
- 国土地理院: 指定緊急避難場所、指定避難所、指定福祉避難所
- 気象庁: 選択地域の警報・注意報
- ハザードマップポータル: 洪水、内水、土砂、津波、高潮の地図レイヤ

防災地図はアプリ画面内で災害種別を切り替えられます。避難場所も重ねられます。地図に色がない場合も、安全を保証する表示にはしません。

選んだ地点と災害レイヤの周辺地図だけを、利用者の操作でオフライン用に保存できます。全国の地図を一括保存する機能はありません。

### 緊急連絡先

119、110、118、#7119、#8000、#9110、171、#9910、中毒110番などを、用途と注意点とともに表示します。

連絡先のボタンを押しても、すぐには電話をかけません。「まだ電話はかかっていません」と表示する確認画面を経て、「電話アプリを開く」を選びます。小さな子どもが触る端末などでは、追加ロックも設定できます。

海上の事件・事故は118、川、湖、池、用水路、プールなどで消防による救助が必要な場合は119です。

### 災害時モード

初回設定や保存データのロックを経由せず、地震、津波、大雨・洪水、土砂災害、台風・暴風、火災、停電、断水、閉じ込め・孤立の行動ガイドを開けます。

各画面は「今すぐすること」「避けること」「安全を確保した後」の順に表示し、状況に関係する緊急連絡先も案内します。

### やさしい日本語とアクセシビリティ

「シンプル表示」と「やさしい日本語」を別々に設定できます。やさしい日本語では、災害時の行動や重要な案内を、短く分かりやすい表現へ切り替えます。

次の設定があります。

- 文字サイズ85%から200%
- 行間と文字間隔
- コントラスト
- 暗い背景
- リンクの下線
- 大きなボタン
- 動きを減らす
- シンプル表示
- やさしい日本語
- 標準、大きな文字、見やすさ優先、やさしい表示のプリセット

地図だけで情報を伝えず、避難場所は一覧でも確認できます。QR以外にファイル共有と印刷も用意しています。

### 印刷とバックアップ

診断結果、備蓄、家の安全、家族の防災計画をA4印刷またはPDF保存できます。端末変更やブラウザのデータ消去に備えて、JSON形式のバックアップも書き出せます。

## 使い始める

1. 最初の画面で、入力内容の扱いを確認します。
2. 保存しない、結果だけ保存、端末保存、暗号化保存から選びます。
3. リスク診断を行うか、後で行うかを選びます。
4. 「スマホに入れる」からホーム画面へ追加します。
5. 備蓄、家の安全、家族の防災計画、地域情報を必要に応じて更新します。
6. 短い防災訓練で、実物と家族の行動を確認します。

災害が起きている場合は、初回設定を行わず「今、災害が起きている」から行動ガイドを開けます。

## 保存とプライバシー

| 保存方法 | 内容 |
|---|---|
| 保存しない | 画面を開いている間だけ利用し、再読込や終了で消去 |
| 診断結果だけ保存 | 質問への回答を残さず、結果の要約と表示設定だけ保存 |
| この端末に保存 | 診断、備蓄、家族の防災計画、訓練記録、地域情報などをブラウザ内へ保存 |
| 暗号化して保存 | 保存内容をAES-GCMで暗号化し、パスフレーズで開く |

通常の診断回答、家族構成、備蓄、賞味期限、家族の防災計画、訓練記録は、EpsilonLabやGitHubのサーバへ送信しません。

地域情報を取得するときだけ、利用者の許可に基づき、選択地点の緯度・経度、検索語、地域コードなどを該当する公的機関へ送ります。通信履歴は端末内で確認・削除できます。

QR共有や共有リンクには、利用者が選んだ家族の防災計画が含まれます。画面やQRを見た人が内容を読める可能性があるため、共有範囲を確認してください。

詳しくは `docs/PRIVACY.md` を参照してください。

## オフライン利用の範囲

初回にオンラインで読み込み、オフライン準備が完了すると、診断、備蓄、家の安全、家族の防災計画、防災訓練、緊急連絡先、災害時ガイドなどの主要機能をオフラインで使えます。

現在の警報、公的データの更新、未保存の地図タイル、住所検索には通信が必要です。オフラインでは、最後に取得した情報を取得時刻付きで表示します。古い情報を現在の情報とみなさず、通信が使える場合は公式情報を確認してください。

## 安全上の注意

このアプリは行政機関の公式アプリではありません。診断は、災害の発生、個人の被害、建物倒壊、生命の危険を予測するものではなく、安全を保証しません。

アプリ内の防災地図は、避難経路の安全を判定しません。地図に色が表示されない場合も、区域外や安全を保証するものではありません。自治体の最新情報も確認してください。

緊急時は現在地の状況と、公的機関、消防、警察、海上保安庁、医療機関、自治体の指示を優先してください。

## 対応環境

最新のSafari、Chrome、Edge、Firefoxを主な対象としています。ブラウザやOSによって、インストール、位置情報、永続保存、共有、地図の表示が異なる場合があります。

JavaScript、IndexedDB、Service Worker、Web Crypto APIに対応していない環境では、一部機能を利用できません。

## 不具合・改善提案

公開リポジトリのIssueで受け付けます。

報告には、住所、氏名、勤務先、職業、病歴、家族構成、正確な位置情報、電話番号、実際のバックアップファイルを書かないでください。個人情報を除いた再現手順だけを共有してください。
