# 診断ルール

## 目的

診断は、個人の被災確率や安全度を算出するものではありません。入力された生活条件から、どの分野を先に確認・改善するとよいかを整理します。

## 分野

1. 地震・家具転倒
2. 洪水・内水氾濫
3. 津波・高潮
4. 土砂災害
5. 台風・暴風
6. 火災・通電火災
7. 停電・断水・生活継続
8. 避難・孤立・連絡

一つの総合災害確率へ合算しません。

## 回答

- はい
- いいえ
- わからない
- あとで確認

「わからない」「あとで確認」「未回答」は、リスク点へ加算しません。同時に安全とも判断せず、判定の確かさを下げ、確認リストへ残します。

## 優先度

質問ごとに、回答が各災害分野へ与える重みを定義します。例えば、津波浸水想定区域、土砂災害警戒区域、医療機器の電源など、単独でも影響が大きい条件には最低優先度を設定します。

表示:

- 0: 情報不足
- 1: 確認を継続
- 2: 少し見直す
- 3: 優先して確認
- 4: 早めに対策
- 5: 最優先で確認

優先度1は「安全」を意味しません。公的ハザード情報が未入力のまま低く見える可能性があるため、各画面に注意書きを表示します。

## 判定の確かさ

分野ごと、および全体で「はい・いいえ」と回答できた割合から表示します。

- A: 85%以上
- B: 60%以上85%未満
- C: 60%未満、または既知回答なし

確かさは診断の精度保証ではなく、入力情報の充足度です。

## 理由と行動

優先度へ加算した回答から、重みの大きい理由を最大4件表示します。推奨行動は重み順に並べ、同じ文を重複表示しません。

対策済みと回答した項目は「すでにできていること」へ表示します。

## 検証

- 同じ回答に同じ結果を返す
- 不明回答は点数を増やさない
- 重大条件の最低優先度が維持される
- 家具未固定などの具体的条件から推奨行動が出る
- 空回答を低リスクと表示しない

自動テストは`tests/risk-engine.test.mjs`にあります。
