# v0.2.0 QA report

この文書は、「守れるいのち」v0.2.0で実施した自動検証とブラウザ動作試験の概要です。

## 対象

- アプリ版: 0.2.0
- データ形式: schemaVersion 2
- 公開先想定: GitHub Pagesのプロジェクトサイト
- 実行時依存: なし
- 対象ブラウザ: 現行のSafari、Chrome、Edge、Firefox

## 静的検証とNode.jsテスト

`npm run check`で、プロジェクト検証とNode.js標準テストを実行しました。

結果:

- プロジェクト検証: 成功
- Node.jsテスト: 28件成功、失敗0件

主な確認内容:

- リスク診断で不明回答を低リスクとして扱わないこと
- 津波、家具未固定などの条件が適切な優先項目へ反映されること
- 水、食料、携帯トイレの3日・7日計算
- 重要項目が不足したまま総合達成にならないこと
- 常用薬、乳幼児、ペットなどの条件付き項目
- 賞味期限・使用期限の分類
- 暗号化バックアップと誤パスフレーズの拒否
- J-SHISの確率を0から1の割合から百分率へ変換すること
- 気象庁の現在の警報JSON構造を解析できること
- 国土地理院の周辺タイル、施設種別ごとの件数確保、距離計算
- J-SHIS対象範囲外座標の事前検出
- GitHub Pagesで使える相対パス
- OGP画像が1200 x 630pxであり、絶対URLが設定されていること
- 外部スクリプト、広告、アクセス解析を読み込まないこと
- 公的データ通信を専用モジュールと許可済み提供元へ限定すること
- `LOCAL_ONLY/`をGit管理対象から除外すること
- 公開文書に個人の絶対パス、秘密鍵、トークンらしき文字列を含めないこと
- 「サーバ」「ブラウザ」の表記に統一すること

## ブラウザ動作試験

GitHub Pagesのサブパスを模したローカルURLで、ヘッドレスChromiumを使用して確認しました。

結果:

- 43項目成功、失敗0件
- 実行時JavaScript例外: 0件
- 重大なconsole error: 0件

主な確認内容:

- 初回案内とプライバシー説明
- 許可前に公的機関への通信が発生しないこと
- Service Workerの登録とページ制御
- 文字サイズ85%、115%、150%、200%の反映
- 文字サイズ変更が小さな1つのボックス内で完結すること
- 文字サイズ変更時に画面を覆う通知を表示しないこと
- 320px幅・文字サイズ200%で横スクロールが発生しないこと
- ホーム、緊急連絡先、災害時モード、地域情報、インストール、ヘルプ、備蓄、家の安全、防災ガイドの描画
- 119の発信前確認
- 任意連絡先の保存と再読込
- 住所を使わない複数地点登録
- 公的データ取得前の送信先・目的・送信内容の確認
- J-SHISの地震動確率表示
- 指定緊急避難場所、指定避難所、指定福祉避難所の区別
- 気象庁の警報・注意報表示
- 外部通信履歴
- オフライン再読込と取得済み地域情報の表示
- Android向けインストール案内
- 新しいService Workerを検出した際に強制再読込しないこと
- 利用者が更新を選んだ後だけ新しいService Workerへ切り替わること
- PWA更新後も端末保存データが残ること

公的データの画面試験では、再現可能性を確保するため、J-SHIS、国土地理院、気象庁の応答を試験用データへ置き換えました。実際の提供元との通信、CORS、応答速度、サービス停止時の挙動は、GitHub Pagesへ公開した後に確認します。

## 更新試験

ローカルの公開用コピーへ版の異なるService Workerを配信し、次を確認しました。

1. 新しいworkerを検出する
2. 待機中のまま更新案内を表示する
3. 利用者の操作前にはページを再読込しない
4. 「更新する」を選んだ後にworkerを切り替える
5. 再読込後もIndexedDBの保存内容が残る

## 公開後に必要な確認

ローカル試験では代替できないため、公開後に次を確認します。

- GitHub ActionsのTestとDeploy GitHub Pages
- 実際の公開URLでのOGP取得とnoteのリンクプレビュー
- v0.1.0を利用していたブラウザでのデータ移行
- インストール済みPWAでのv0.1.0からv0.2.0への更新
- iPhone、iPad、Android、PCでのインストール
- 実機の機内モードでの起動
- 実際のJ-SHIS、国土地理院、気象庁との通信
- VoiceOver、TalkBack、キーボード操作
- A4印刷とPDF保存

## 試験の限界

試験の成功は、災害時の安全、公的データの完全性、個別住宅の安全性を保証するものではありません。公的情報の仕様変更に備え、取得日時、提供元、失敗時の公式導線を維持し、継続的に更新します。
