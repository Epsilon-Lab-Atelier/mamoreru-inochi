## PWAとService Workerの検証

静的検証と自動テストで、次を確認しました。

- アプリ本体、v0.3.0の新規モジュール、QRライブラリ、画面画像を事前キャッシュ対象に含める
- GitHub Pagesのサブパスで解決できる相対URLを使う
- install時に新しいWorkerを強制適用しない
- 新しいWorkerをwaiting状態で保持し、利用者が更新を選んだ後だけ切り替える
- 利用者が明示保存した周辺地図を、版更新時に一律削除しない
- 公的なJSON情報の通信を、アプリ画面で許可した操作から直接行う

実際のGitHub Pages上でのService Worker更新、インストール済みv0.2.0からの切替、OSごとのホーム画面追加は公開後に確認します。

## 公的リンク

公的リンクの404・410を週1回確認するGitHub Actionsを追加しました。リリース作業時にも主要な公式ページを確認しています。

試験の成功は、災害時の安全、公的データの完全性、個別住宅の安全性を保証するものではありません。公的情報の仕様変更やリンク変更に備え、取得日時、提供元、失敗時の公式導線を維持し、継続的に更新します。
