## PWAとService Workerの検証

静的検証と自動テストで、次を確認しました。

- アプリ本体、QRライブラリ、画面画像を事前キャッシュ対象に含める
- GitHub Pagesのサブパスで解決できる相対URLを使う
- install時に新しいWorkerを強制適用しない
- 新しいWorkerをwaiting状態で保持し、利用者が更新を選んだ後だけ切り替える
- v0.3.1への更新だけを理由に、利用者が明示保存した周辺地図を削除しない
- 保存地図を削除するときは、旧版を含む地図キャッシュから対象URLを削除する
- 公的なJSON情報の通信を、アプリ画面で許可した操作から直接行う

実際のGitHub Pages上でのService Worker更新、インストール済みv0.3.0からの切替、OSごとのホーム画面追加は公開後に確認します。

## 公的リンクと外部仕様

公的リンクの404・410を週1回確認するGitHub Actionsを用意しています。J-SHISの地震ハザード情報APIについては、公式仕様に基づき、経度・緯度とEPSGを指定し、任意の`attr`は省略して全属性を取得する構成です。

ローカル実行環境から外部サイトへ接続できない場合、`npm run check:links`は通信警告を表示します。通信不能は404・410と同一視せず、定期Actionsと公開後の手動確認を併用します。
