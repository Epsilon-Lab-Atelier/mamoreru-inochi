# アクセシビリティ

## 目標

WCAG 2.2 Level AAを設計目標とし、高齢者、視覚・運動・認知面で支援が必要な利用者、スマートフォンの片手操作を考慮します。

## 表示と操作

- 文字サイズ85%、100%、115%、130%、150%、175%、200%
- 行間1.5から2.1
- 文字間隔4段階
- 高コントラスト
- 暗色表示
- リンクの下線
- 大きなボタン
- 動きを減らす
- シンプル表示
- やさしい日本語
- 標準、大きな文字、見やすさ優先、やさしい表示のプリセット
- `prefers-reduced-motion`対応

文字サイズはルート要素へ適用し、見出し、本文、ボタンを一貫して拡大します。文字サイズの変更は小さな1つのボックス内で行い、画面を覆う通知を表示しません。

## 構造

- スキップリンク
- 見出し階層とランドマーク
- キーボードフォーカスの可視化
- ルート移動後の見出しフォーカス
- ネイティブフォーム要素
- 選択肢全体をタップ可能
- 色だけに依存しない状態表示
- ARIA liveによる短い通知
- 制限時間なし
- 印刷用スタイル

## 地図とQRの代替

- 地図は上下左右、拡大、縮小ボタンでも操作可能
- 避難場所は地図だけでなく、名称、住所、距離、対応災害の一覧でも表示
- QR共有以外に、共有リンク、JSONファイル、A4印刷を用意
- 地図の色だけで災害種別や安全性を伝えない

## 緊急時画面

- 初期設定を経由しない
- 保存データのロック解除を経由しない
- 「今すぐすること」「避けること」「安全確保後」の順
- 119、110、118などは番号だけでなく用途を併記
- 電話は用途確認と「電話アプリを開く」の操作を経る
- 開発者紹介、支援依頼、広告を表示しない

## 手動確認項目

- VoiceOver
- TalkBack
- 200%文字拡大
- 320px幅
- キーボードのみ
- 高コントラストと暗色表示
- 地図の非ドラッグ操作
- QR共有以外の代替手段
- 印刷プレビュー
- 更新案内、通信許可、電話確認の読み上げ順
