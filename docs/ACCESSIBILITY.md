# アクセシビリティ

## 目標

WCAG 2.2 Level AAを基本目標とし、高齢者、視覚・運動・認知面で支援が必要な利用者、スマートフォンの片手操作を考慮します。

## v0.2.0の主な対応

- 文字サイズ85%、100%、115%、130%、150%、175%、200%
- ルート要素へ倍率を適用し、見出し、本文、ボタンを一貫して拡大
- 文字サイズ選択を小さな1つのボックス内に表示
- 高コントラスト
- 動きを減らす
- 1列中心のやさしい表示
- スキップリンク
- 見出し階層とランドマーク
- キーボードフォーカスの可視化
- ネイティブフォーム要素
- 選択肢全体をタップ可能
- 最小約44から48pxの操作領域
- 色と文字を併用した状態表示
- ARIA liveによる短い通知
- ルート移動後の見出しフォーカス
- 制限時間なし
- 印刷用スタイル
- `prefers-reduced-motion`対応
- 地図がなくても避難場所を文字リストで確認可能
- 外部通信の確認を、見出し、説明、選択ボタンのあるダイアログで表示

## 緊急時画面

- 初期設定を経由しない
- ロック解除を経由しない
- 「今すぐすること」「避けること」「安全確保後」の順
- 119、110、118など、状況に合う連絡先を文字で表示
- 番号だけでなく用途を併記
- 開発者紹介、支援依頼、広告を表示しない

## 手動確認項目

- VoiceOver / TalkBack
- 200%文字拡大
- 320px幅
- キーボードのみ
- 高コントラスト
- 暗色表示
- 印刷プレビュー
- 明るい屋外と暗所を想定した見え方
- 更新案内と通信許可ダイアログの読み上げ順
