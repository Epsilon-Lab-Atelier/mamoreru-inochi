# アクセシビリティ

## 目標

WCAG 2.2 Level AAを基本目標とし、特に高齢者、視覚・運動・認知面で支援が必要な利用者、スマートフォン片手操作を考慮します。

## v0.1.0

- 文字サイズ100%〜200%
- 高コントラスト
- 動きを減らす
- 1列中心のやさしい表示
- スキップリンク
- 見出し階層とランドマーク
- キーボードフォーカスの可視化
- ネイティブフォーム要素
- ラジオ選択肢全体をタップ可能
- 最小約44〜48pxの操作領域
- 色と文字を併用した状態表示
- ARIA liveによる短い通知
- ルート移動後の見出しフォーカス
- 制限時間なし
- 印刷用スタイル
- prefers-reduced-motion対応

## 緊急時画面

- 初期設定を経由しない
- ロック解除を経由しない
- 最初の行動、避けること、安全確保後の順
- 119、110を大きく表示
- 開発者紹介、支援依頼、広告を表示しない

## 手動確認

- VoiceOver / TalkBack
- 200%文字拡大
- 320px幅
- キーボードのみ
- 高コントラスト
- 印刷プレビュー
- 明るい屋外と暗所を想定した見え方
