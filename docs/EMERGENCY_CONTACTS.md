# 緊急連絡先の扱い

## 基本原則

命に危険がある場合は、相談窓口を待たず緊急通報を優先します。

| 番号 | 主な用途 |
|---|---|
| 119 | 火災、救急、消防による救助 |
| 110 | 事件、交通事故、身の危険 |
| 118 | 海上の事件、事故、遭難 |
| #7119 | 救急車や受診の判断に迷う場合の相談。実施地域のみ |
| #8000 | 子どもの休日・夜間の病気やけがの相談 |
| #9110 | 緊急ではない警察相談 |
| 171 | 災害用伝言ダイヤル |
| #9910 | 道路の穴、崩壊、落下物などの道路異状 |
| 中毒110番 | 医薬品、家庭用品、化学物質などの中毒相談 |

## 水難事故

- 海上の遭難、転落、船舶事故: 118
- 川、湖、池、用水路、プールなどで消防の救助が必要: 119
- 事件性や交通事故がある: 110も状況に応じて利用

自分が危険になる無理な救助は避け、浮く物を投げる、位置を伝えるなど、安全を確保しながら通報します。

## 発信前の確認

アプリでは、番号を押しただけで電話アプリへ移りません。用途と注意点を確認するダイアログを表示し、利用者が「電話アプリを開く」を選んだ場合に`tel:`リンクを開きます。

誤操作を抑えるための設計であり、緊急通報を遅らせる目的ではありません。

## 地域差

#7119などは、実施地域、受付時間、利用できる回線が異なります。利用前に居住地域の案内を確認してください。

## 任意連絡先

次のような連絡先を端末内へ登録できます。

- 家族、親族
- 自治体の防災窓口
- 水道、電力、ガス
- 管理会社、大家
- 学校、保育施設、職場
- かかりつけ医、薬局、動物病院

氏名や詳細な医療情報は必須ではありません。共有端末では暗号化保存を推奨します。
