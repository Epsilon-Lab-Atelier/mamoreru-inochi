# 緊急連絡先の扱い

## 基本原則

命に危険がある場合は、相談窓口を待たず緊急通報を優先します。

| 番号 | 主な用途 |
|---|---|
| 119 | 火災、救急、消防による救助 |
| 110 | 事件、交通事故、身の危険 |
| 118 | 海上の事件、事故、遭難 |
| #7119 | 救急車や受診の判断に迷う場合の相談。実施地域のみ |
| #8000 | 子どもの休日・夜間の病気やけがの相談 |
| #9110 | 緊急ではない警察相談 |
| 171 | 災害用伝言ダイヤル |
| #9910 | 道路の穴、崩壊、落下物などの道路異状 |
| 中毒110番 | 医薬品、家庭用品、化学物質などの中毒相談 |

## 水難事故

- 海上の遭難、転落、船舶事故: 118
- 川、湖、池、用水路、プールなどで消防の救助が必要: 119
- 事件性や交通事故がある: 状況に応じて110

自分が危険になる無理な救助は避け、浮く物を投げる、位置を伝えるなど、安全を確保しながら通報します。

## 発信前の確認

連絡先一覧には、直接発信する`tel:`リンクを置きません。

1. 「発信前に確認する」を選ぶ
2. 「まだ電話はかかっていません」と表示する確認画面を読む
3. 番号と用途が現在の状況に合うか確認する
4. 「電話アプリを開く」を選ぶ
5. 端末の電話画面で、利用者自身が最終操作を行う

確認画面を開いた直後のキーボードフォーカスは「キャンセル」に置きます。誤タップやEnterキーだけで電話アプリへ移らない設計です。

## 追加ロック

共有端末や小さな子どもが触る端末では、「緊急電話の誤操作防止を強くする」を任意で有効にできます。

有効時は、用途確認に加えて解除操作を行ってから電話アプリへ進みます。実際の緊急時に操作を増やしすぎないよう、標準設定は2段階確認です。

災害時モードでは、追加ロックを10分間だけ解除できます。解除中も用途確認画面は省略しません。

## #9110の案内

緊急ではない警察相談には、警察相談専用電話#9110を案内します。公式説明は、現在利用可能な警察庁の次のページを参照します。

- 警察庁「ご意見・ご要望」: https://www.npa.go.jp/goiken_notes.html
- 警察庁 SOS47: https://www.npa.go.jp/bureau/safetylife/sos47/

リンク切れとなった旧URLは使用しません。

## 地域差

#7119などは、実施地域、受付時間、利用できる回線が異なります。利用前に居住地域の案内を確認してください。#8000や各種相談窓口も、時間帯や混雑によりつながりにくい場合があります。

## 任意連絡先

次のような連絡先を端末内へ登録できます。

- 家族、親族
- 自治体の防災窓口
- 水道、電力、ガス
- 管理会社、大家
- 学校、保育施設、職場
- かかりつけ医、薬局、動物病院

氏名や詳細な医療情報は必須ではありません。共有端末では暗号化保存を推奨します。家族の防災計画をQRやファイルで共有する場合、電話番号は標準では共有対象にしません。
