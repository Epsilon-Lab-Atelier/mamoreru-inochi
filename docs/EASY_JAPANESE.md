# やさしい日本語

## シンプル表示との違い

- シンプル表示: 画面の並びを1列中心にして、情報量を減らします
- やさしい日本語: 文そのものを短く、分かりやすくします

この2つは別々に切り替えられます。

## 優先する内容

v0.3.1では、次の重要な画面からやさしい表現を用意します。

1. 災害時の行動
2. 緊急連絡先
3. スマホへのインストール
4. 初回のプライバシー説明
5. 家族の防災計画
6. 防災訓練
7. 備蓄と地域情報

## 方針

- 一文を短くする
- 主語と行動を明確にする
- 専門語には説明を付ける
- 重要な番号や行動は省略しない
- 「安全」と断定しない
- 自動翻訳や生成AIでその場に応じて文章を作らない

通常の日本語とやさしい日本語は、公開前に個別に確認します。
