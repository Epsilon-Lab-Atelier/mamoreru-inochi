# 防災訓練

## 方針

点数や順位を付ける訓練ではありません。短い時間で実物と家族の行動を確認し、気づいた不足を備蓄や家族計画へ反映します。

## 時間

- 3分
- 5分
- 10分

## シナリオ

- 夜中に大きな地震
- 大雨で避難を考える
- 停電と断水
- 家族が別々の場所にいる
- 自宅で火災
- 道路寸断・孤立
- エレベータ停止
- スマホの通信がつながらない

## 記録

- 確認できた項目
- 気づいたこと
- 次回までに行うこと
- 実施日時
- 次回の見直し日

記録は選択した保存方法に応じて端末内へ保存します。EpsilonLabへ送信しません。

## カレンダー

次回の訓練日をiCalendar形式で書き出せます。OSのバックグラウンド通知へ依存せず、利用者自身のカレンダーで予定を管理できます。
