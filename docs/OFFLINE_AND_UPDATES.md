# オフライン利用と更新

## インストール

「守れるいのち」はPWAです。対応ブラウザでは、ホーム画面またはアプリ一覧へ追加できます。

### iPhone・iPad

1. Safariで公開ページを開く
2. 共有ボタンを押す
3. 「ホーム画面に追加」を選ぶ
4. 名前を確認して追加する

### Android

1. Chromeで公開ページを開く
2. アプリ内の「インストール」またはブラウザメニューを開く
3. 「アプリをインストール」または「ホーム画面に追加」を選ぶ

### PC

ChromeまたはEdgeのアドレス欄付近に表示されるインストールボタン、またはブラウザメニューからインストールします。

ブラウザやOSの版により、文言と位置が異なる場合があります。

## オフラインで使える内容

初回オンライン読込後にService Workerの準備が完了すると、次をオフラインで利用できます。

- リスク診断
- 備蓄計算と登録済み備蓄
- 家の安全チェック
- 家族計画
- 緊急連絡先
- 災害時行動ガイド
- アプリ内ヘルプ
- 最後に取得して端末保存した地域情報

## 通信が必要な内容

- J-SHISの更新
- 国土地理院の避難場所データ更新
- 新しい地図タイル
- 気象庁の警報・注意報更新
- アプリの新しい版の取得

オフライン時は古い情報が表示される可能性があります。取得時刻を確認してください。

## 更新方式

GitHub Pagesへ新しい版が公開されると、ブラウザは新しいService Workerを検出します。

アプリは次の機会に更新を確認します。

- 起動時
- オンラインへ戻ったとき
- アプリが前面へ戻ったとき
- 一定時間ごと
- 「更新を確認」を押したとき

新しい版を検出しても、入力途中に強制再読込しません。画面上部に更新案内を表示し、利用者が「更新する」を押した時点で新しいWorkerへ切り替えます。

## 更新されない場合

1. 通信が利用できることを確認する
2. 「インストールと更新」から「更新を確認」を押す
3. アプリを一度閉じて開き直す
4. ブラウザ版の公開ページを開き直す

保存データはIndexedDBにあり、通常のアプリ更新では削除しません。ただし、ブラウザのサイトデータを削除すると失われるため、必要な場合は先にバックアップを書き出します。

## オフライン動作の確認

1. オンラインでアプリを一度開く
2. 「インストールと更新」でオフライン準備状態を確認する
3. 診断結果や災害時ガイドを一度開く
4. 機内モードへ切り替える
5. アプリを再度開き、主要画面を確認する

現在の警報や地域情報の更新は、機内モードでは利用できません。
