# スマホへの追加、オフライン利用、更新

## このアプリをスマホに入れる理由

「守れるいのち」は、通常のWebページとしても使えますが、スマホのホーム画面へ追加すると次の利点があります。

- 災害時にURLを探さず、アイコンからすぐ開ける
- 診断結果、備蓄、家族の防災計画を持ち歩ける
- 通信が不安定でも主要な行動ガイドを確認できる
- 新しい版が公開された場合も、同じアイコンから更新できる
- アプリストア、アカウント登録、広告がない

アプリ内では「PWAをインストールする」よりも、「スマホに入れる」「ホーム画面に追加する」という表現を使います。

## アプリ内の案内

未追加の端末では、ホーム画面上部にインストールカードを表示します。閉じた場合は繰り返し強く表示せず、「スマホに入れる」画面からいつでも手順を確認できます。

インストール案内は、災害時モード、緊急連絡先の確認画面、診断入力中には表示しません。

## iPhone・iPad

1. Safariで公開ページを開く
2. 共有ボタンを押す
3. 「ホーム画面に追加」を選ぶ
4. 表示される設定を確認する
5. 「追加」を押す

note、LINE、SNS等のアプリ内ブラウザでは、「ホーム画面に追加」が表示されない場合があります。その場合はメニューからSafariで開き直します。

## Android

1. Chrome等の対応ブラウザで公開ページを開く
2. アプリ内の「スマホに入れる」を押す
3. ブラウザの「アプリをインストール」または「ホーム画面に追加」を確認する
4. 追加する

環境がアプリ内インストール操作に対応していない場合は、ブラウザメニューから追加します。

## PC

ChromeまたはEdgeでは、アドレス欄付近のインストールボタン、またはブラウザメニューから追加できます。

PCで開いた利用者には、スマホで公開URLを開くためのQRコード、URLコピー、共有機能を表示します。

## インストール済みの状態表示

インストール済みと判定できる場合、ホーム画面の勧誘カードは表示しません。代わりに次を確認できます。

- 現在のアプリ版
- オフライン準備
- 保存方法
- 更新の有無
- 最終バックアップ
- 地域情報の取得日時

ブラウザによってはインストール済みか完全に判定できないため、「すでにホーム画面へ追加しました」を選べるようにしています。

## オフラインで使える内容

初回オンライン読込後にService Workerの準備が完了すると、次をオフラインで利用できます。

- リスク診断
- 備蓄計算と登録済み備蓄
- 家の安全チェック
- 家族の防災計画と共有データの作成
- 防災訓練
- 緊急連絡先
- 災害時行動ガイド
- アプリ内ヘルプ
- 最後に取得して端末保存した地域情報
- 利用者が明示的に保存した周辺地図

## 通信が必要な内容

- 住所・施設名検索
- J-SHISの更新
- 国土地理院の避難場所データ更新
- 未保存の地図タイル
- 気象庁の警報・注意報更新
- 新しいアプリ版の取得

オフライン時は古い情報が表示される可能性があります。取得時刻を確認してください。

## 周辺地図の限定保存

全国地図は保存しません。利用者が選んだ地点、災害レイヤ、縮尺の周辺だけを保存します。

保存前に、対象地点、災害種別、取得先を表示します。保存した地図は自動更新されないため、取得日を確認し、不要になった場合は削除してください。

アプリ本体を更新しても、利用者が明示的に保存した周辺地図は自動削除しません。削除操作を行った場合は、旧版で作成された地図キャッシュも含めて対象タイルを削除します。

## 更新方式

GitHub Pagesへ新しい版が公開されると、ブラウザは新しいService Workerを検出します。

アプリは次の機会に更新を確認します。

- 起動時
- オンラインへ戻ったとき
- アプリが前面へ戻ったとき
- 一定時間ごと
- 「更新を確認」を押したとき

新しい版を検出しても、診断や備蓄の入力途中に強制再読込しません。画面上部に更新案内を表示し、利用者が「更新する」を選んだ時点で新しいWorkerへ切り替えます。

アプリ本体の更新では、通常、IndexedDBの診断・備蓄・家族の防災計画を削除しません。保存形式を変更する版では、旧形式を読み込み、既定値を補完し、整合性を確認してから新形式で保存します。

## 更新されない場合

1. 通信が利用できることを確認する
2. 「スマホに入れる・更新」画面から「更新を確認」を押す
3. アプリを完全に閉じて開き直す
4. ブラウザ版の公開ページを開き直す
5. それでも変わらない場合は、設定画面で現在の版を確認する

ブラウザのサイトデータを削除すると保存内容も失われます。再インストールやサイトデータ削除の前に、必要に応じてバックアップを書き出します。

## オフライン動作の確認

1. オンラインでアプリを一度開く
2. 「スマホに入れる・更新」でオフライン準備状態を確認する
3. 災害時ガイド、家族の防災計画、備蓄結果を一度開く
4. 必要な地点の周辺地図を保存する
5. 機内モードへ切り替える
6. アプリを開き、主要画面と取得時刻を確認する

現在の警報や地域情報の更新は、機内モードでは利用できません。
