# 公的資料と内容管理

## 方針

- 可能な限り国・自治体・公的事業者の一次資料を使う
- 数値は出典と用途を明記する
- アプリ独自の実用目安と公的基準を区別する
- 短い抜粋にとどめ、本文を複製しない
- 内容確認日を記録する
- リンクが開くだけでなく、アプリ本文との整合を確認する

## v0.1.0の主な資料

`src/data.js`の`OFFICIAL_SOURCES`に、組織、資料名、URL、利用箇所、確認日を保持します。

主な用途:

- 内閣府: 水、食料、3日・7日備蓄
- 内閣府: 携帯トイレ1日5回
- 気象庁: 地震、津波、大雨、台風の行動
- 消防庁: 119番
- 警察庁: 110番
- NTT東西: 災害用伝言ダイヤル171
- 国土交通省: 住宅の耐震確認
- 国土地理院: 指定緊急避難場所

## アプリ独自の目安

次は家庭差が大きく、公的な一律必要量ではありません。

- 照明の個数
- ラジオの台数
- モバイル電源の充電回数
- ヘルメットと手袋
- カセットボンベ
- 給水容器
- 救急用品セット

画面上で「アプリ内の実用目安」と明記します。

## 更新

半年に一度、または制度・名称変更時に確認します。変更時は:

1. `src/data.js`
2. アプリ本文
3. `CHANGELOG.md`
4. `checkedAt`
5. 関連テスト

を更新します。
