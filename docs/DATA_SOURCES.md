# 公的資料とデータ連携

## 方針

- 可能な限り国、公的研究機関、公的事業者の一次資料を使う
- 数値、情報名、利用目的、内容確認日を明記する
- 公的な確率とアプリ独自の優先度を区別する
- 外部データは利用者の明示的な操作で取得する
- 取得時刻と提供元を画面に表示する
- 公的データが最新でない、未掲載、停止中である可能性を説明する
- 災害時は自治体などの最新公式情報を優先する

## 地域情報

### J-SHIS

提供元: 防災科学技術研究所

利用するAPI属性:

- `T30_I45_PS`: 今後30年間に震度5弱以上となる確率
- `T30_I50_PS`: 今後30年間に震度5強以上となる確率
- `T30_I55_PS`: 今後30年間に震度6弱以上となる確率
- `T30_I60_PS`: 今後30年間に震度6強以上となる確率

APIは0から1の割合で返すため、画面では100倍して百分率に換算します。APIの対象範囲は日本周辺の経度122〜154度、緯度20〜46度であり、範囲外の地点は取得前に案内します。確率が低いことは、地震が起きないことや、建物が安全であることを意味しません。

### 国土地理院

利用する地理院タイル:

- `skhb01`: 洪水に対応する指定緊急避難場所
- `skhb02`: 崖崩れ、土石流、地滑りに対応する指定緊急避難場所
- `skhb03`: 高潮に対応する指定緊急避難場所
- `skhb04`: 地震に対応する指定緊急避難場所
- `skhb05`: 津波に対応する指定緊急避難場所
- `skhb06`: 大規模な火事に対応する指定緊急避難場所
- `skhb07`: 内水氾濫に対応する指定緊急避難場所
- `skhb08`: 火山現象に対応する指定緊急避難場所
- `sih`: 指定避難所
- `sfh`: 指定福祉避難所
- `pale`: 淡色地図

指定緊急避難場所、指定避難所、指定福祉避難所は役割が異なります。指定福祉避難所には受入対象や開設条件があります。データが最新でない、または未掲載の場合があるため、自治体の最新情報と受入条件を必ず確認します。

### 気象庁

選択した府県予報区等の地域コードを使い、警報・注意報JSONを取得します。

アプリは発表時刻、見出し、対象地域コード、情報名、状態を表示します。気象庁の情報名やデータ構造が変更された場合にも、不明なコードを捨てずにコード付きで表示します。

警報・注意報は自治体の避難指示ではありません。避難情報は自治体の公式情報も確認してください。

## アプリ独自の目安

次は家庭差が大きく、公的な一律必要量ではありません。

- 照明の個数
- ラジオの台数
- モバイル電源の充電回数
- ヘルメットと手袋
- カセットボンベ
- 給水容器
- 救急用品セット

画面上で「アプリ内の実用目安」と明記します。

## 更新手順

半年に一度、または制度、名称、API、提供URLの変更時に確認します。

1. 公的機関の一次資料を確認
2. `src/data.js`と`src/public-data.js`を更新
3. 画面の説明と注意事項を更新
4. `checkedAt`を更新
5. 自動テストと実ブラウザ相当QAを実施
6. `CHANGELOG.md`へ記録
