# 地点登録と防災地図

## 地点の選び方

v0.3.1では、緯度・経度を直接入力しなくても地点を登録できます。新しい地点で地図を開くと、日本全体が見える位置から始まります。

1. 現在地から探す
2. 住所・施設名から探す
3. 地図から選ぶ
4. 詳細設定で座標を直接入力する

現在地の取得だけでは地点を保存しません。地点名と位置を確認し、「地点を登録する」を選んだ時点で端末内へ保存します。

住所・施設名検索では、入力した検索語を国土地理院の検索サービスへ送ります。現在地、検索語、座標は、許可した操作以外で外部へ送信しません。


## 地図中央と操作

地点を選ぶ地図では、中央に赤い照準と「登録する場所」を固定表示します。地図を動かしても照準は中央に残り、「赤い照準の場所を選ぶ」を押した時点で座標をフォームへ反映します。

スマホで地図を動かしている間は、表示済みの地図画像をそのまま移動します。指を離した後にだけ必要なタイルを更新するため、操作のたびに画面全体を作り直しません。地図タイルは画面内に必要な範囲へ絞ります。

## アプリ内防災地図

背景地図は国土地理院の地理院タイルを使用します。次の災害レイヤを切り替えられます。

- 洪水浸水想定区域
- 内水浸水想定区域
- 土砂災害警戒区域
- 津波浸水想定
- 高潮浸水想定区域

避難場所・避難所を追加表示できます。複数の災害レイヤは原則として同時に重ねず、1種類ずつ確認します。

## 地図を読み取るときの注意

- 地図に色がないことは、安全を保証しません
- 未整備、未掲載、縮尺、取得失敗などで表示されない場合があります
- 自治体の最新ハザードマップも確認してください
- アプリは安全な避難経路を判定しません
- 災害時には道路、橋、地下道、崖、冠水など現地の状況を優先してください

## オフライン保存

利用者が明示的に選んだ地点、災害レイヤ、縮尺の周辺地図だけを保存します。全国地図の一括保存は行いません。

保存した地図には取得時刻を表示し、不要になった場合は削除できます。公的情報の更新は自動ではないため、通信が使えるときに再取得してください。

## 地図が操作しにくい場合

ドラッグ操作以外に、上下左右、拡大、縮小のボタンを用意しています。避難場所は地図だけでなく、名称、住所、距離、対応災害の一覧でも確認できます。
