# Threat Model

## 守る対象

- 診断回答
- 家族構成と支援条件
- 備蓄量と保管場所
- 家族の集合場所と役割
- バックアップ
- パスフレーズ

## 想定する脅威

1. 共有端末を使う別の利用者
2. バックアップファイルの紛失
3. ブラウザーデータの消去
4. XSSや外部スクリプトによる読み取り
5. 公開リポジトリへの秘密情報混入
6. 古いService Workerや古い防災内容
7. 利用者が診断を安全保証と誤認すること

## 対策

- 保存しないモード
- 結果だけ保存
- AES-GCM暗号化保存
- パスフレーズ非保存
- CSP
- 外部JavaScript/CDN/解析/広告なし
- ユーザー入力のHTMLエスケープ
- JSON形式検証
- バックアップ警告
- 完全削除
- バージョン付きService Worker Cache
- 診断結果の免責と「確率ではない」表示
- 公的出典と確認日
- Issueテンプレートで個人情報を禁止

## 対象外・残るリスク

- 端末やOSが侵害されている
- 悪意あるブラウザー拡張
- 入力中の肩越し閲覧・画面撮影
- パスフレーズの使い回しや弱い管理
- GitHub Pagesや通信事業者の通常アクセスログ
- 端末故障
- 利用者がバックアップを安全でない場所へ置く
- 緊急時に端末・電源・通信を使えない

暗号化は万能ではなく、紙の計画、公的な緊急情報、家族内の確認を置き換えません。
