# Threat Model

## 守る対象

- 診断回答
- 家族構成と支援条件
- 備蓄量、期限、保管場所
- 家族の集合場所、避難先、役割
- 訓練記録
- 登録地点の緯度・経度
- 任意連絡先
- 公的情報の取得履歴
- QR・共有リンク・バックアップ
- パスフレーズ

## 想定する脅威

1. 共有端末を使う別の利用者
2. QRコード、共有リンク、バックアップの紛失や誤共有
3. ブラウザデータの消去
4. XSSや外部スクリプトによる読み取り
5. 公開リポジトリへの秘密情報混入
6. 古いService Worker、古い地図、古い防災情報
7. 許可前の位置情報、検索語、公的情報送信
8. 公的提供元の停止、変更、不正な応答
9. 緊急電話の誤操作
10. 地図の無表示を安全と誤認すること
11. アプリが安全な避難経路を示すと誤認すること
12. 診断や備蓄達成度を安全保証と誤認すること

## 対策

- 保存しない、結果だけ保存、端末保存、暗号化保存
- パスフレーズ非保存
- CSPで実行コード、画像、通信先を制限
- 外部JavaScript、CDN、解析、広告なし
- 動的通信を`src/public-data.js`へ集約
- 通信前に送信先、送信内容、目的を明示
- 現在地取得と公的情報取得を別操作に分離
- 共有項目を選択し、機微情報を標準で除外
- 受信データを確認してから取り込む
- ユーザー入力のHTMLエスケープ
- JSON形式と版の検証
- 完全削除とオフライン地図の個別削除
- バージョン付きService Worker Cache
- 新Workerを利用者操作で切り替え
- 取得時刻、提供元、オフライン状態を表示
- 電話番号の一覧に直接の`tel:`リンクを置かない
- 「まだ電話はかかっていません」の確認と任意の追加ロック
- 地図に色がない場合も安全を保証しない注意
- 避難経路の安全を判定しない
- 公的リンクの定期検査
- Issueテンプレートで個人情報を禁止

## 残るリスク

- 端末やOSの侵害
- 悪意あるブラウザ拡張
- 肩越し閲覧、画面撮影
- 弱いパスフレーズや使い回し
- GitHub Pages、公的提供元、通信事業者の通常アクセスログ
- 公的データの未掲載、遅延、誤り
- 公的APIやURLの予告ない変更
- 端末故障、電池切れ、通信障害
- QRやバックアップを安全でない場所へ置くこと
- 災害時にアプリだけを頼ること

暗号化、地図、診断は万能ではありません。紙の計画、公的な緊急情報、家族内の確認、自治体の最新情報と併用します。
