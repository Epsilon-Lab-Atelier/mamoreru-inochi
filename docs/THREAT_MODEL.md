# Threat Model

## 守る対象

- 診断回答
- 家族構成と支援条件
- 備蓄量と保管場所
- 家族の集合場所と役割
- 登録地点の緯度・経度
- 任意登録した連絡先
- 公的情報の取得履歴
- バックアップ
- パスフレーズ

## 想定する脅威

1. 共有端末を使う別の利用者
2. バックアップファイルの紛失
3. ブラウザデータの消去
4. XSSや外部スクリプトによる読み取り
5. 公開リポジトリへの秘密情報混入
6. 古いService Workerや古い防災情報
7. 許可前の位置情報・地域情報送信
8. 公的データ提供元の停止、変更、不正な応答
9. 外部リンクや電話番号の誤操作
10. 利用者が診断や取得情報を安全保証と誤認すること

## 対策

- 保存しないモード
- 結果だけ保存
- AES-GCM暗号化保存
- パスフレーズ非保存
- CSPで実行コードと通信先を制限
- 外部JavaScript、CDN、解析、広告なし
- 外部通信処理を`src/public-data.js`へ集約
- 通信前に送信先、送信内容、目的を明示
- 現在地取得と公的情報取得を別操作に分離
- 通信履歴を端末内で表示・削除
- HTTP応答、タイムアウト、JSON形式を検証
- ユーザー入力のHTMLエスケープ
- JSONバックアップ形式検証
- 完全削除
- バージョン付きService Worker Cache
- 新Workerを強制適用せず、利用者操作で切り替え
- 公的情報へ取得時刻と提供元を表示
- 電話番号を押した後に用途確認を表示
- 診断結果の免責と「個人の被災確率ではない」表示
- 公的出典と確認日
- Issueテンプレートで個人情報を禁止

## 対象外・残るリスク

- 端末やOSが侵害されている
- 悪意あるブラウザ拡張
- 入力中の肩越し閲覧・画面撮影
- パスフレーズの使い回しや弱い管理
- GitHub Pages、公的データ提供元、通信事業者の通常アクセスログ
- 公的データが最新でない、未掲載、誤りを含む
- 公的APIや公開URLが予告なく変更される
- 端末故障、電池切れ、通信障害
- 利用者がバックアップを安全でない場所へ置く
- 緊急時にアプリだけを頼り、現地の危険や公的指示を見落とす

暗号化、地図、診断は万能ではなく、紙の計画、公的な緊急情報、家族内の確認、自治体の最新情報を置き換えません。
