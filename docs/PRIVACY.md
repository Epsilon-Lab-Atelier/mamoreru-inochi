# プライバシー設計

## 基本方針

v0.1.0は、診断回答、家族構成、備蓄、賞味期限、家族計画を外部へ送信しません。

アカウント、広告、アクセス解析、外部フォーム、外部JavaScript、外部フォント、現在地取得、クラウド同期はありません。

## GitHub Pagesとの関係

GitHub PagesはアプリのHTML、CSS、JavaScript、画像を配信します。入力データはPagesへ書き込まれません。

通常のWebアクセスに伴うIPアドレス等は、ホスティング事業者や通信事業者の運用上の記録対象になる可能性があります。アプリの診断回答や備蓄情報をアクセスログへ含める処理はありません。

## 端末保存

IndexedDBのデータベース名:

```text
mamoreru_inochi_v1
```

他のEpsilonLabアプリからこのデータを読むコードはありません。

## 暗号化

- 鍵導出: PBKDF2 / SHA-256 / 250,000 iterations
- 暗号: AES-GCM / 256bit
- Salt: 16 bytes random
- IV: 12 bytes random

パスフレーズは保存・送信しません。暗号化は、同じブラウザーを使う他者や、バックアップファイルの平文閲覧を抑えるための機能です。端末そのものの侵害、悪意ある拡張機能、OS管理者、入力中の画面閲覧などを完全には防げません。

## データ最小化

- 氏名不要
- 生年月日不要
- 正確な住所不要
- 電話番号不要
- 病名・薬名不要
- 位置情報不使用

家族計画は関係や役割だけでも入力できます。

## バックアップ

暗号化保存以外のバックアップは平文JSONです。利用者へ、個人情報が含まれる可能性と安全な保管を案内します。

暗号化保存のバックアップは、保存時と同じ方式で暗号化します。

## 削除

設定画面から、IndexedDBのmetadataとapp-dataを削除し、アプリ状態を初期化できます。Service Workerのキャッシュはアプリ本体であり、利用者の診断内容を含まないため残します。
