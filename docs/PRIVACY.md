# プライバシー設計

## 基本方針

「守れるいのち」v0.3.0は、診断回答、家族構成、備蓄、賞味期限、家族計画、防災訓練、任意連絡先を、利用者が選んだ方法で端末内に保存します。

アカウント、広告、アクセス解析、外部フォーム、外部JavaScript、外部フォント、クラウド同期はありません。

## GitHub Pagesとの関係

GitHub Pagesは、アプリ本体を配信します。端末内へ入力した診断や備蓄データをPagesへ書き込む処理はありません。

通常のWebアクセスに伴うIPアドレスなどは、ホスティング事業者や通信事業者の運用上の記録対象になる可能性があります。診断回答や備蓄情報をURLやアクセスログへ含める処理はありません。

## 端末保存

主な保存先はIndexedDBです。v0.1.0から同じデータベースを継続して使用します。

```text
データベース名: mamoreru_inochi_v1
ストア名: records
データ形式: schemaVersion 3
```

v0.2.0以前の内容は、既定値を補完し、整合性を確認してから新形式へ保存します。

## 保存モード

- `none`: 永続保存しない
- `result`: 回答や個別情報を残さず、診断結果の要約と表示設定だけ保存
- `full`: 診断、備蓄、家族計画、訓練、地域情報、任意連絡先を端末内へ保存
- `protected`: `full`相当の内容を暗号化して保存

`result`では、位置情報、通信履歴、家族構成、備蓄詳細、家族計画、訓練記録、任意連絡先を保存しません。

## 暗号化

- 鍵導出: PBKDF2 / SHA-256 / 250,000 iterations
- 暗号: AES-GCM / 256bit
- Salt: 16 bytes random
- IV: 12 bytes random

パスフレーズは保存・送信しません。端末そのものの侵害、悪意ある拡張機能、入力中の画面閲覧などを完全には防げません。

## 公的情報を取得するときの通信

| 提供元 | 送信する情報 | 目的 |
|---|---|---|
| J-SHIS | 選択地点の緯度・経度 | 地震動確率の取得 |
| 国土地理院 | 検索語、緯度・経度、地図タイル番号 | 住所検索、避難場所、背景地図 |
| ハザードマップポータル | 地図タイル番号 | 洪水、内水、土砂、津波、高潮レイヤ |
| 気象庁 | 選択した地域コード | 警報・注意報の取得 |

EpsilonLabのサーバを経由せず、ブラウザから各公的機関へ直接問い合わせます。通信前に、送信先、内容、目的を表示します。

現在地を取得しただけでは、公的機関への通信を開始しません。地点名と位置を確認して登録できます。

## 家族計画の共有

QRコード、共有リンク、JSONファイルには、利用者が選んだ家族計画が含まれます。標準では電話番号、正確な位置、支援情報、自由記述メモを共有しません。

共有データはEpsilonLabへ送信しませんが、QRコードやリンクを見た人は内容を読める可能性があります。共有する相手と場所を確認してください。

受信側では、内容を確認し、利用者が「取り込む」を選んだ場合だけ端末へ保存します。

## 防災訓練

訓練の実施日時、確認項目、気づき、次回までの行動を端末内へ保存します。点数、ランキング、外部送信はありません。

## 任意連絡先

家族、自治体、管理会社、学校、かかりつけ医などを登録できます。内容は端末内で扱います。共有端末では保存しないか暗号化保存を利用してください。

## バックアップ

暗号化保存以外のバックアップは平文JSONです。家族計画、備蓄場所、登録地点、任意連絡先が含まれる場合があります。安全な場所へ保管してください。

## 削除

設定画面から、取得済み地域情報、通信履歴、任意連絡先、オフライン地図、全保存データを削除できます。
