# プライバシー設計

## 基本方針

「守れるいのち」v0.2.0は、診断回答、家族構成、備蓄、賞味期限、家族計画、任意連絡先を、利用者が選んだ方法で端末内に保存します。

アカウント、広告、アクセス解析、外部フォーム、外部JavaScript、外部フォント、クラウド同期はありません。

## GitHub Pagesとの関係

GitHub Pagesは、アプリのHTML、CSS、JavaScript、画像、マニフェストを配信します。端末内へ入力した診断や備蓄データを、Pagesへ書き込む処理はありません。

通常のWebアクセスに伴うIPアドレスなどは、ホスティング事業者や通信事業者の運用上の記録対象になる可能性があります。診断回答や備蓄情報をURLやアクセスログへ含める処理はありません。

## 端末保存

主な保存先はIndexedDBです。

```text
データベース名: mamoreru_inochi_v1
ストア名: records
```

v0.1.0と同じデータベースを継続して使用し、既存データをv0.2.0の構造へ補完します。

## 保存モード

- `none`: 永続保存しない
- `result`: 回答や個人設定を残さず、診断結果の要約と表示設定だけ保存
- `full`: 診断、備蓄、家の安全、家族計画、地域情報、任意連絡先を端末内へ保存
- `protected`: `full`相当の内容を暗号化して保存

`result`では、位置情報、緯度・経度、通信履歴、家族構成、備蓄詳細、任意連絡先を保存しません。

## 暗号化

- 鍵導出: PBKDF2 / SHA-256 / 250,000 iterations
- 暗号: AES-GCM / 256bit
- Salt: 16 bytes random
- IV: 12 bytes random

パスフレーズは保存・送信しません。暗号化は、同じブラウザを使う他者や、バックアップファイルの平文閲覧を抑えるための機能です。端末そのものの侵害、悪意ある拡張機能、OS管理者、入力中の画面閲覧などを完全には防げません。

## 公的情報を取得するときの通信

地域情報は、利用者が各操作を選び、確認画面で許可した場合だけ取得します。

| 提供元 | 送信する情報 | 目的 |
|---|---|---|
| 防災科学技術研究所 J-SHIS | 選択地点の緯度・経度 | 地震動確率の取得 |
| 国土地理院 | 緯度・経度から計算した地図タイル番号 | 指定緊急避難場所、指定避難所、指定福祉避難所、地図の取得 |
| 気象庁 | 選択した地域コード | 警報・注意報の取得 |

EpsilonLabのサーバを経由せず、ブラウザから各公的機関へ直接問い合わせます。通信時には、各機関や通信事業者が通常の接続情報を取り扱う可能性があります。

許可は「今回だけ」または「この端末で今後も許可」から選べます。保存済みの許可、取得結果、通信履歴は設定画面から削除できます。

現在地の取得は、ブラウザまたはOSの位置情報許可に基づき、地点フォームへ緯度・経度を入力するために使います。現在地を取得しただけでは、公的機関への通信を開始しません。

## 任意連絡先

家族、自治体、管理会社、学校、かかりつけ医などの名称と電話番号を登録できます。内容は端末内で扱い、外部へ送信しません。

共有端末では、保存しないか、暗号化保存を利用してください。

## データ最小化

- 氏名は必須にしない
- 生年月日は必須にしない
- 正確な住所は入力しない
- 病名・薬名は必須にしない
- 現在地は利用者が操作したときだけ取得
- 地域情報は緯度・経度と地域コードだけで問い合わせ
- 緊急連絡先は任意登録

## バックアップ

暗号化保存以外のバックアップは平文JSONです。家族計画、備蓄場所、登録地点、任意連絡先が含まれる場合があります。安全な場所へ保管してください。

暗号化保存のバックアップは、保存時と同じ方式で暗号化します。

## 削除

設定画面から次を削除できます。

- 取得済み地域情報
- 通信履歴
- 任意連絡先
- 診断・備蓄・家族計画を含む全保存データ

Service Workerのキャッシュはアプリ本体を保存するものであり、診断回答や備蓄情報を含みません。
